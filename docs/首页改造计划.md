# 首页改造计划（Hero + Landing + Online Demo）

> 状态：方案已确认，未动工。关联：release sea base v0.2.0（`3d-assets`）、上轮视频压缩方案。
> 待定：① landing 中英双语（×1.5 工作量）② 静态托管 R2 vs 子域名 ③ 首批世界（云南/澄江/…？）

## 一、页面信息架构（首屏往下）

```
Hero（全屏，保留 3D 视频但换加载逻辑）
 → 数字条（活项目感）
 → 三步拥有远古海洋（how it works）
 → 世界画廊（静态图卖体验）
 → 科学背书条（信任状）
 → 页脚（现有 sidebar-bottom 复用）
```

现有侧边栏导航保留（Discovery / Archive / What's New），只把首页 `page.tsx`
主内容区从纯视频换成上述长页；视频 hero 收敛为第一屏。

## 二、Hero 改造

* **加载分层**：poster 图（压成 webp ~60KB）→ 叠"正在潜入三叠纪海洋…"（1s 内出现，
  LCP 就它了）→ 视频 `preload="none"`，`onCanPlay` 后淡入开播。秒开封面，3D 随后流进来。
* **文案**（可直接用）：
  * 主标题：潜入 2.4 亿年前的海洋
  * 副标题：亲手布置你的三叠纪海底世界，不用写一行代码
  * 主按钮「免费进入」→ `/demo`；次按钮「看看别人建的世界」→ `#gallery` 锚点
  * 小字：拖拽看看四周（视频角上 3 秒后淡出，解决没人发现可交互）
* **移动端**：不自动播，封面 + 大播放钮，点才播。

## 三、Online Demo（release sea 上线版）

核心决策：**sea 构建产物不进 Next 仓库**（76MB 进 git 是灾难）。

* 新增 `/demo` 路由：全屏 iframe，`src` 指向静态托管的 sea base 包
  （如 `https://demo.deep-time-studio.com/` 或 R2 桶，`?scene=` 透传）。
* 打包侧加 `pack_demo.py`（复用 `pack_base` 逻辑，输出 `scene-demo.json` + 去掉 exe，
  只要 `scene/` 静态文件夹）→ 传到静态托管。
* 画廊每张图链 `/demo?world=yunnan` 这类预设：`world` 参数映射不同 scene JSON
  （云南 / 澄江各一个，由 base JSON 改摆位衍生，不用重做模型）。
* iframe 标题 + loading 态复用 Hero 那套"正在潜入…"，体验统一。

## 四、各区块内容清单

* **数字条**：物种数 = 库真实计数（trilobites + amphibians + triassic marine 求和，
  构建时注入）；世界数 = 画廊世界数；已创建场景数——v1 不上真实计数，
  用占位文案，二期接 Umami 事件或计数 API（不写死数字）。
* **三步**：选世界（挑一片海，云南/澄江各有性格）→ 放置生物（从模型库拖进场景，
  所见即所得）→ 分享场景（导出 JSON，发给朋友原样还原）。配图用 sea 实机截图。
* **画廊**：3d-maker preview 渲染图 + sea 实机截图，静态 `next/image`（avif/webp），
  点图进 `/demo?world=xxx`。
* **背书条**："每一个生物，都有化石证据支撑" → 链 `/archive/trilobites`。

## 六、顺序与验收

顺序：视频压缩 + poster → landing 长页（纯静态，最快见效）→ `/demo` + 静态托管
→ world 预设 → 数字条真实计数。

`/demo` 首屏 5 秒可交互。
